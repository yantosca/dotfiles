# Code of Conduct

This is a personal dotfiles repository, maintained for individual use and shared publicly for
reference and convenience. It is not a community project with active governance, but if you
interact with it (issues, pull requests, discussions) the following applies:

- Be respectful and constructive in any comments, issues, or pull requests.
- Assume good faith; keep feedback focused on the content, not the person.
- Harassment, personal attacks, or discriminatory language will not be tolerated and may result
  in comments being deleted or the interaction being blocked.

## Reporting

If you experience or witness unacceptable behavior related to this repository, contact
yantosca@seas.harvard.edu.
